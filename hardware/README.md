# *Muse Cube* Embedded Platform: Hardware

The reference build is based on a Raspberry Pi 5 and uses commercial off-the-shelf components for audio I/O, wireless connectivity, and enclosure design. All parts can be replaced with compatible alternatives to adapt the platform to specific needs.

## Components

The reference hardware includes:

- Raspberry Pi 5

- Waveshare PCIe to M.2 E Key HAT for Raspberry Pi 5

- Waveshare Wireless AX210 NIC (Wi-Fi 6E, Bluetooth 5.3)

- HiFiBerry DAC+ ADC Pro

**Notes**
The platform is designed to support audio, MIDI, and networked music applications.
External USB-MIDI devices can be connected through the Raspberry Pi USB ports.
Compatible substitute components can be used to personalize the build.
